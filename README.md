# BuildRadar MVP

**Find your next commercial construction opportunity before your competitors do.**

BuildRadar is a zero-to-one MVP for commercial construction opportunity intelligence, starting with Cumming / Forsyth County, Georgia.

## MVP

- Project discovery dashboard
- Opportunity scoring (0-100)
- Construction stage tracking
- Trade/scope matching
- Verified source links
- Search and filters
- Project detail view
- Contractor-oriented call-to-action

## Product thesis

Start as an information and qualified-lead product rather than a GC or construction operator. Capture early-stage commercial projects, identify the likely timing and scopes, and match those opportunities to specialty contractors.

## Local focus

The seed dataset focuses on real commercial projects in and around Cumming / Forsyth County. Project data is explicitly marked with source URLs and should be re-verified before commercial use.

## Run locally

Open `index.html` in a browser, or deploy the repository with GitHub Pages / any static host.
